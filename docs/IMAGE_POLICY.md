# 图片政策（Phase 1.1）

Claude App 的整批写稿任务提供每篇最多三个已核实可用候选 `image_candidates` 和最多三个授权待确认推荐 `image_recommendations`。程序不联网搜索、下载图片或上传 Google Drive。

## 默认操作

全部稿件通过独立核验后，使用 03 检查正文和 `image-guide.md`，再使用 05 审核、批准并导出。无需 04、候选转备选、登记本地图片或逐篇确认无图。每篇最终目录保留 `article.md` 和 `image-guide.md`，编辑随后自行选择、下载一张或多张图片并手动上传 Google Drive。外部图片处理不代表无图发布，也不代表程序确认了实际使用。

## 已核实可用（须遵守所列条件）

候选须有可核实、适用于具体图片及预期编辑用途的 PUBLIC_DOMAIN、OPEN_LICENSE、OFFICIAL_PRESS_LICENSE 或 OWNED 依据。记录原始页面、原图链接（可空）、作者／权利方、授权页面、许可名称、使用范围、资格、第三方限制和必要署名，并给出推荐原因及画面说明。找不到可靠授权时保持空列表，不保证每篇都有可用图片。

授权页面可以是图片文件页、适用的全站媒体政策、开放许可证或可记录的书面授权。官方身份、下载按钮或版权标记单独不能证明使用权限。CC0 不强制署名；开放许可须记录作者及许可名称。资料图、产品差异和非事件照片须准确说明。禁止把搜索缩略图或 fair use 假设当作许可。

## 推荐使用，授权待确认

推荐保留相关图片来源、原图链接（可空）、作者／权利线索、推荐原因及具体缺口：PAGE_INACCESSIBLE（页面无法访问）、INSUFFICIENT_EVIDENCE（授权证据不足）、RESTRICTED_USE（存在不适用的明确限制）。推荐不等于授权；下载使用前须解决所列问题。有明确限制时需取得适用的另行授权。

## 存储与旧流程兼容

SQLite 保留已核实候选；原始推荐来自哈希验证的归档 content result。工作区和最终交付均生成一份可阅读的 `image-guide.md`，最终指南纳入导出哈希清单及清理完整性检查。最终导出成功后可以删除过程材料而保留指南。历史已清理批次不重建已删除推荐。

旧批次已经登记的原图和许可继续验证、导出，不改变既有选用记录。原图片计划、候选补充 CLI 和 manual-image-candidates.json 草稿保留兼容能力，但不属于新默认流程。已选图文章仍须验证本地原图、归属和权利记录；不能用外部图片处理绕过损坏的旧登记记录。
