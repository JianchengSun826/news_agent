# Source Policy

优先使用公司官方博客、新闻稿、开发者文档、GitHub release、论文、监管文件和官方研究页面。Reuters、AP、Bloomberg、FT、WSJ、Ars Technica、The Verge、TechCrunch 等可靠媒体用于独立核验和背景。

Reddit、Hacker News、X、论坛和用户评论只可用于 discovery，不能单独支持关键事实。每个重要事实必须能追溯到 URL；不可访问或相互矛盾的信息放入 Research Brief 的 unknown/conflicting sections。

不得虚构来源或引用、根据模型记忆补充最新事实、绕过 paywall，或大规模复制新闻正文。数据库只保存 URL、metadata、短编辑笔记和必要短摘录。候选必须有一个实际打开且支持 `core_fact` 的 primary URL；secondary URL 可选。只有 primary 的候选必须明确归因，涉及安全、财务、法律、监管争议或重大数字的事实应在写稿前获得独立核验。错误或无关的 secondary URL 必须移除并记录，不能为了凑齐来源而保留。
